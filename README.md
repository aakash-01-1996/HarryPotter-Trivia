## Harry Potter Trivia

- Think you know Hogwarts? Calling all Potterheads — take the ultimate trivia challenge!

## Live Link
[https://youtube.com/shorts/mcKmeV5gFX0](https://youtube.com/shorts/N7rHOmra4Vw?feature=share)

## Features

- Choose specific books from the Harry Potter series to customize your quiz
- Multiple choice questions with scoring system
- Themed backgrounds and UI inspired by the wizarding world
- Smooth UI animations and transitions using SwiftUI's declarative syntax
- Tracks progress and score
